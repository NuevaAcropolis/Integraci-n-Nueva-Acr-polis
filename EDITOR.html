Panel simple de actualización

La web funciona sola; tú solo actualizas datos y fotos.

Fotos

Talleres: img/actividades/. Equipos: img/espacios/. Luego cambia el nombre en data/agenda.js o data/espacios.js.

Agenda

Abre data/agenda.js. Con desde y hasta una actividad puede repetirse durante meses. dias:[1] es lunes y dias:[7] domingo.

Suspender

Para una fecha usa canceladas:["2026-09-24"]. Para una semana completa usa SEMANAS_SIN_ACTIVIDADES.

Galería de cada equipo

En data/espacios.js: fotos:["foto1.jpg","foto2.jpg","foto3.jpg"].

También tienes el archivo COMO_ACTUALIZAR.txt con ejemplos.
